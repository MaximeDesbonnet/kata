# Gilded Rose

Le kata Gilded Rose en TypeScript. Règles métier : [GildedRoseRequirements_fr.md](GildedRoseRequirements_fr.md).

## Démarrer

```sh
npm install
npm test               # tests unitaires + golden master (Vitest)
npm run typecheck      # vérification des types
npm run test:coverage  # couverture
npm run golden-master -- 10   # inventaire de référence sur 10 jours
```
